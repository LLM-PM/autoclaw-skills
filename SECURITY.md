# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable security issues, credentials, tokens, private endpoints, customer data, or other sensitive information in a public issue.

If a security issue concerns a public skill definition, open a GitHub issue only when it can be described safely without exposing sensitive details. For issues that require confidential disclosure, contact the maintainer through an appropriate private channel associated with the maintainer's GitHub profile.

## Sensitive-content policy

This repository must not contain:

- API keys, access tokens, passwords, cookies, or secrets;
- internal-only endpoints or infrastructure details;
- customer or employee personal data;
- proprietary documentation or code without permission;
- confidential company workflows or non-public operational data.

Contributors are responsible for verifying that submitted material is authorized for public release.
